# 🗺️ Контурна карта: Україна та світ

Інтерактивна навчальна контурна карта в **одному HTML-файлі**: без збирання, без фреймворків і без встановлення. Є мапа України (області, річки, населені пункти) та мапа світу (країни, столиці, річки, океани й моря). Можна вивчати географію, проходити тести, робити позначки, малювати й друкувати.

> ⚠️ **Мапа навчальна й спрощена.** Не використовуйте її для точних вимірювань, навігації чи юридичних цілей. Докладніше в розділі [Точність даних](#-точність-даних).

## ✨ Можливості

### Дві мапи
| | Україна | Світ |
|---|---|---|
| **Об'єкти** | області (разом з АР Крим), обласні центри, річки | країни, столиці, річки, океани й моря |
| **Додатково** | населені пункти за областями (міста, селища, села) | фільтр за материками |
| **Пошук** | села й міста | країни, столиці, річки |

### Режими
- **Вивчення**: натисніть на об'єкт, щоб побачити інформацію. Можна вмикати й вимикати підписи.
- **Тест**: питання кількох типів:
  - знайти область, річку чи обласний центр на мапі;
  - назвати центр області або область за містом;
  - знайти місто за координатами;
  - змішаний режим.

  Для мапи світу питання про країни й столиці аналогічні.

### Інструменти
- 🖱️ вибір і переміщення мапи, масштабування;
- 📍 позначки з підписом;
- 📏 лінійка;
- ✏️ малювання (5 кольорів);
- 🧹 очищення позначок і малюнків;
- 🖨️ друк (інтерфейс на папері приховується).

### Шари
Річки · Обласні центри / Столиці · Кольорова заливка · Координатна сітка · Підписи (усі / жодного)

Інтерфейс адаптивний: працює на комп'ютері, планшеті й телефоні.

## 🚀 Швидкий старт

1. Завантажте файл і відкрийте його в браузері (подвійний клік).
2. Або розмістіть на **GitHub Pages**: перейменуйте файл на `index.html`, потім **Settings → Pages → Deploy from a branch**.

Збирати чи встановлювати нічого не потрібно.

## 🌐 Інтернет і кеш

- Мапа **України** й усі її дані вбудовані у файл і працюють офлайн.
- Мапа **світу** при першому відкритті завантажує контури країн (GeoJSON `worldLow.json` з пакета [`@amcharts/amcharts4-geodata`](https://www.npmjs.com/package/@amcharts/amcharts4-geodata)) через CDN. Є кілька дзеркал, і якщо одне недоступне, пробується наступне.
- Після успішного завантаження дані зберігаються в `localStorage` браузера, і далі мапа світу працює **без інтернету**.
- У режимі інкогніто чи після очищення даних сайту завантаження доведеться повторити.

Якщо мапа світу не завантажується, натисніть «Спробувати ще раз». Подробиці будуть у консолі браузера (F12), в рядках `geo fail …`.

## 🎯 Точність даних

- **Світ**: низька деталізація (`worldLow`). Дрібні держави й острови спрощені або відсутні.
- **Спірні території** показані за політикою автора набору даних і можуть не збігатися з українською та міжнародною позицією.
- **Україна** малюється за власними контурами областей, разом з Кримом, а не з даних світу.
- Через різні джерела **на кордонах України з сусідами** можливі невеликі щілини чи накладання.

Помітили помилку? Створіть [issue](../../issues) і вкажіть об'єкт та скриншот.

## 🛠️ Технології

Чистий HTML, CSS і JavaScript, векторна графіка SVG. Залежностей і етапу збирання немає. Єдиний зовнішній ресурс — контури країн для мапи світу (див. вище).
